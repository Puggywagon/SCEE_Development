## AI Refresher

> *Conceptual scaffold — starting point before reading. Expand and refine from textbooks.*

Automation transforms SCEE from procedure applicable to handful of cases into one deployable routinely and reproducibly. Makes approach tractable at scale needed for meaningful physical results.

**Full pipeline automation:**
- Configuration extraction from MD trajectory
- QM/MM input file preparation
- Job submission and monitoring
- Output parsing and charge extraction
- Iterative MM environment updating
- Convergence checking
- Dipole moment extraction
- Results aggregation across ensemble

**Benefits beyond removing manual burden:**
- Reproducibility — every calculation follows exactly same procedure
- Parameter space becomes explorable — vary MM region size, number of configurations, convergence threshold, QM method systematically
- Error checking built in at every stage

Specific implementation details described in simulation details section of chapter.
