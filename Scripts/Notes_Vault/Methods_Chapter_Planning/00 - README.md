# PhD Theory Vault

> *A focused vault for building up theory notes from textbooks and AI refreshers, developing them into thesis-ready writing.*

---

## Structure

### Theory Folders (01-09)
Each folder maps to a section of the methodology chapter. Contains:
- Numbered subsection notes — AI refresher + textbook notes + thoughts
- Synthesis note — pulling it together for writing
- Loose Notes — scratchpad for things that don't fit neatly
- Canvas — visual overview of the section

### Equations
Equation cards — equation in LaTeX, term breakdown, physical interpretation, sources, connections.

### Other Bits (10)
Useful notes that don't fit the methodology chapter structure — water chapters, fixed charge model history, book introductions etc.

### Canvases
- **Methodology Chapter** — chapter level overview
- **Master Canvas** — full thesis picture

### Templates (00)
- Subsection Note Template
- Equation Card Template
- Synthesis Template
- Loose Notes Template
