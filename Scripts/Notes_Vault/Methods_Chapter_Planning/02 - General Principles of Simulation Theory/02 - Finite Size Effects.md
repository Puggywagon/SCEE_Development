## AI Refresher

> *Conceptual scaffold — starting point before reading. Expand and refine from textbooks.*

Despite PBC your system is still periodically infinite not truly infinite. Finite size effects are residual errors because your box is still small.

Key effects:
- Periodic image interaction — if box too small, molecule interacts with its own image
- Phase transitions suppressed — fluctuations occur on length scales exceeding box size
- Long range correlations artificially truncated

Validation: run same simulation at several box sizes and check property of interest has converged — finite size scaling analysis.
