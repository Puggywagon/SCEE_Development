# Equation — Canonical Partition Function

**Topic:** See connections below
**Tags:** #statmech #equation
**Status:** #to-verify

---

## Equation

$$
Z = \sum_i e^{-\beta E_i} = \sum_i e^{-E_i / k_B T}
$$

---

## Term Breakdown

| Symbol | Meaning | Units |
|--------|---------|-------|
| $Z$ | Canonical partition function (also written Q) | Dimensionless |
| $E_i$ | Energy of microstate i | J |
| $\beta$ | Inverse temperature $1/k_BT$ | J⁻¹ |
| $i$ | Index running over all accessible microstates | — |

---

## Physical Interpretation

The weighted sum over all microstates in the canonical ensemble. Despite looking like a normalisation constant, Z encodes everything about the equilibrium thermodynamics of the system. All thermodynamic quantities can be derived from Z by taking appropriate derivatives.
