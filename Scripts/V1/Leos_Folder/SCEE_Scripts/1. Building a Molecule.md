### How the Relevant Functions Work

Generally the two scripts below are identical. There are few steps skipped in the UA that are present in the AA due to the molecules being identical. There are also a few steps that have been commented out in the UA relating to my attempts to how I was trying to make a UA model. More info can be found on this in the [Other Notes] section below. 

`Chem.MolFromSmiles(mol)` 
This part of the script generates a structure based on the smile string provided. Some more details on how smile strings actually work for RDKit are shown below.

`Chem.AddHs(mol)`
This step then adds the H's to the molecule. I did notice based on the coordinates the Ethanediol test I had done, the H's heteroatoms (i.e O, N), seem to add first, then those on the carbons.

`Chem.AllChem.EmbedMolecule(mol)`
This generates an initial 3D conformation for the molecule. Up to this point, the molecule only exists as a 2D connectivity graph (atoms and bonds from the SMILES string, plus the hydrogens just added). `EmbedMolecule` uses the **ETKDG algorithm** (distance geometry) to place every atom at a set of 3D coordinates that are physically reasonable — respecting bond lengths, angles, and chirality. The result is stored as a "conformer" on the mol object, which is why later in your code you can call `mol.GetConformer().GetAtomPosition(i)` to retrieve each atom's x, y, z position. (borrowed from Claude)

`Chem.AllChem.UFFOptimizeMolecule(mol)`
This refines the 3D coordinates produced by the previous step using the **Universal Force Field (UFF)**. The embedding step gives a reasonable but not necessarily energy-minimised geometry. UFF is a classical force field that models the physical forces between atoms (bonds, angles, torsions, van der Waals, etc.) and iteratively adjusts atom positions to minimise the overall potential energy of the molecule. The output is a more physically realistic, lower-energy 3D structure — which is important for the coordinates that end up in your `.gro` file, since those will be used as starting positions in your simulation. This is sort of similar to how you would build a molecule using Avogadro. (also borrowed from Claude)

`img = Chem.Draw.MolToImage(mol)`
This step and those involving plt, helps generate an image of the molecule. This gives you something visual to check you have generated the correct molecule. I will note that isn't a very accurate image in terms of stereochemistry for instance but it is a good visual check. There are probably ways to make these more accurate but I will likely stick with ChemDraw etc.

We then use our writing block to give each atom a number, loop through the list to generate positions, which are originally generated in angstrom and so are converted to nm. We obtain the atoms symbol from this. We use the system title for pure solvents to name the molecule, this can probably be changed when we make our new version. We then write this information in a format that gromacs will accept to perform the simulation. We start with a box size of 0.0 0.0 0.0, as gromacs requires us to assign a box size before we start running anything.

**AA_Structure**
```Python
    def AA_Structure(self,mol,system_title,resname):
        mol = Chem.MolFromSmiles(mol)
        # Generate 3D coordinates
        mol = Chem.AddHs(mol)
        Chem.AllChem.EmbedMolecule(mol)
        Chem.AllChem.UFFOptimizeMolecule(mol)

        img = Chem.Draw.MolToImage(mol)
        plt.imshow(img)
        plt.axis("off")
        plt.savefig(f'{system_title}.png', dpi=300)  
        plt.clf()

        with open(f"{system_title}_AA.gro", 'w') as f:
            # Write header
            f.write(f"{system_title}_AA\n")
            f.write(f"{mol.GetNumAtoms()}\n")
            # Write atom section
            for i, atom in enumerate(mol.GetAtoms()):
                pos = (mol.GetConformer().GetAtomPosition(i))/10
                symbol=atom.GetSymbol()
                f.write(f"{1:5d}{resname:5s}{symbol:5s}{i+1:5d}{pos.x:8.3f}{pos.y:8.3f}{pos.z:8.3f}\n")
            box_size = 0.0
            f.write(f"{box_size:10.5f}{box_size:10.5f}{box_size:10.5f}")
```

### Other Notes
**How SMILE Strings Work**

This is a quick intro to how smile strings work, based on examples:

Capital letters usually means this is in string. Small letters usually shows a ring, with a number used to show where the ring starts and ends, the number shows what ring. () Usually shows a branched group. = shows a double bond, while # is a triple bond (will need to see how to handle these in python since # is also a comment). Hydrogens are not included. + and - are used to show charges.

CCO - Ethanol
CC(=O)C - Acetone
c1ccccc1 - Benzene

ChatGPT aren't very good at generating these yet but you can find them on PubChem. They can get complicated fast.
