### The Goal of these scripts

There are several scripts involved with this section.  I have grouped these based on if they generate or use the NVT_Vacuum as this is used in several places within the scripts. We Generate and output a range of properties and these are used in a variety of locations throughout this processes. I have split the how they work and how they run per script and then combined additional notes and how they have been changed in the new versions. I  will note that there is also a lot of overlap in the processes involved when it comes to the three guassian calculations presented with the main differences being the inputs and outputs rather than how the scripts work. They all use dat_generation.py to generate the structure of the input files used which will be detailed at the end. I had used the SCEE.py to build the basic structure with some modifications. As a result there are a lot of imports and inputs in these scripts that aren't really needed and have been removed from the newer version of these scripts.

### How the Relevant Functions Work

This script starts by checking the molecule in gromacs using `gmx check`. This is a check on if the molecule structure generated by rdkit in [[1. Building a Molecule]] is actually going to function as it should be. We then edit the configuration the box to give it a size based on our calculated L value. I found that having L=L+1.7 worked the best. You need to start with a big enough box when you go to insert the solvent molecules. Too big and the NpT in the next sequence, detailed in [[3. The Production Run]], will not converge, too small and the molecules will not have enough wiggle room in the NVT step in the next sequence. It is a delicate balance where 1.7 worked well and for all of the systems I have run so far. I have come to the conclusion of it works well, don't change it. I don't have a very good reason for why 1.7 works it just does. We do a quick check of the box to make sure nothing broke.

We then take the gro file this generates and perform a minimisation and equilibration of the box. The main goal is to start with the molecule and make sure it is in a form to insert the calculated number of solvent molecules in the next steps. Running the nvt_vacuum2, conveniently gives us an output to run our [Vacuum], [PCM1] and [PCM2] calculations with.

We then use the output to use `gmx dipoles` to calculate the dipole moment of the model in the vapour phase. We don't really do anything with this yet but I have it in here because I dunno if it is something that could be useful. I have however found that when I run this step it causes the production run gromacs steps to stop printing out the info about it running. So now the only way I know the production run is actually running is any print out steps earlier in the process but sometimes this doesn't even work.

        # gmx mdrun -s topol.tpr -v -c argon_1ns.gro -nice 0
        gromacs.mdrun('-v', deffnm='em',ntmpi=1, ntomp=6, pin='on', pinoffset=12)

class Vacuum(object):
    def __init__(self):
        self.runname = 'TIP4P2005'

        #self.basis_v1 = 'aug-cc-pvtz'
        #self.method_v1 = 'b3lyp'
        self.basis_v0 = '6-31+G(d,p)'
        self.method_v0 = 'b3lyp'
        self.basis_v1 = 'aug-cc-pvtz'
        self.method_v1 = 'blyp'
        self.natom = 6
        self.rundir='./opt-test_vacuum'
        self.g09root='/home/zoe/Software/Gaussian/g09_pgi'
        self.GAUSS_SCRDIR = '/home/zoe/Research/Gaussian/scratch'
        self.dat_generation=Dat_Generation(filename='nvt_vacuum2.gro')
################################################################################
    def init_v0(self,system_title,sol_keyword, workdir='./'):
        dat_atoms,dat_xs,dat_ys,dat_zs=self.dat_generation.gro_to_dat()
        text = f'%chk={system_title}_vacuum.chk' + '\n'        
        text += f'%nproc={self.nproc}' + '\n'
        text += f'#p {self.method_v0}/{self.basis_v0} gfprint fopt=tight' + '\n'
        text += '# nosymm pop=full scf=(verytight) density=current\n'
        text += '# integral=(ultrafine,NoXCTest)\n\n'
        text += f'{sol_keyword}\n\n'
        text += '0 1\n'
        for dat_atom,dat_x,dat_y,dat_z in zip(dat_atoms,dat_xs,dat_ys,dat_zs):
            text += f'{dat_atom:s} {dat_x:9.4f} {dat_y:8.4f} {dat_z:8.4f}\n
        text += '\n'
        text  += f'--Link1--\n'              
        text += f'%chk={system_title}_vacuum.chk' + '\n'        
        text += f'%nproc={self.nproc}' + '\n'
        text += f'#p {self.method_v0}/{self.basis_v0} gfprint fopt=tight' + '\n'
        text += '# nosymm pop=full scf=(verytight) density=current\n'
        text += '# integral=(ultrafine,NoXCTest) geom=checkpoint\n\n'
        text += f'{sol_keyword}\n\n'
        text += '0 1 \n\n\n\n'
        if (not os.path.isdir(workdir + self.rundir)):
            os.mkdir(workdir + self.rundir)
        f = open(workdir + self.rundir+'nvt_vacuum.dat', 'w')
        f.write(text)
        f.close()
################################################################################
    def run_gaussian(self, step=0):
        step_str = ''
        text  = '#!/bin/bash' + '\n'
        text += f'cd {self.rundir}' + '\n'
        text += f'export g09root={self.g09root}' + '\n'
        text += 'source $g09root/g09/bsd/g09.profile' + '\n'
        text += f'export GAUSS_SCRDIR={self.GAUSS_SCRDIR}' + '\n'
        text += f'for datfile in $(ls *.dat); do' + '\n'    
        text += '  outfile=${datfile%.dat}.out' + '\n'    
        text += '  echo "g09 < ${datfile} > ${outfile}"' + '\n'    
        text += '  g09 < ${datfile} > ${outfile}' + '\n'    
        text += 'done' + '\n'
        f = open(f'run_{step_str}.sh', 'w')
        f.write(text)
        f.close()
        cmd = ['bash', f'run_{step_str}.sh']
        check_call(cmd)
################################################################################
    def read_multipoles(self, filename):
        f = open(filename, 'r')
        text_file = f.read()
        f.close()
        multipole = {}
        re_dipole = ' Dipole moment \(field-independent basis, Debye\):(?:.*\n){2}'
        raw_data = re.findall(re_dipole, text_file, re.M)
        data = raw_data[-1].split('\n')
        dipole_data = data[1].split()
        multipole['x'] = float(dipole_data[1])
        multipole['y'] = float(dipole_data[3])
        multipole['z'] = float(dipole_data[5])
        multipole['total dipole'] = float(dipole_data[7])
        re_quad = ' Quadrupole moment \(field-independent basis, Debye-Ang\):(?:.*\n){3}'
        raw_data = re.findall(re_quad, text_file, re.M)
        data = raw_data[-1].split('\n')
        quad_data = data[1].split()
        multipole['xx'] = float(quad_data[1])
        multipole['yy'] = float(quad_data[3])
        multipole['zz'] = float(quad_data[5])
        quad_data = data[2].split()
        multipole['xy'] = float(quad_data[1])
        multipole['xz'] = float(quad_data[3])
        multipole['yz'] = float(quad_data[5])
        re_oct = ' Octapole moment \(field-independent basis, Debye-Ang\*\*2\):(?:.*\n){4}'
        raw_data = re.findall(re_oct, text_file, re.M)
        data = raw_data[-1].split('\n')
        quad_data = data[1].split()
        multipole['xxx'] = float(quad_data[1])
        multipole['yyy'] = float(quad_data[3])
        multipole['zzz'] = float(quad_data[5])
        multipole['xyy'] = float(quad_data[7])
        quad_data = data[2].split()
        multipole['xxy'] = float(quad_data[1])
        multipole['xxz'] = float(quad_data[3])
        multipole['xzz'] = float(quad_data[5])
        multipole['yzz'] = float(quad_data[7])
        quad_data = data[3].split()
        multipole['yyz'] = float(quad_data[1])
        multipole['xyz'] = float(quad_data[3])
        return multipole
################################################################################
    def get_multipole_statistics(self):
        raw_dict = {}
        case_dict = {1: 'dipole_l', 2: 'dipole_m', 3: 'dipole_h'}        
        for Q in range(1,4):
            filelist = glob.glob(self.rundir + f'nvt_vacuum.out')
            for filename in filelist:

                config = filename.split('_')[-3].replace('c', '')
                if (config not in raw_dict):
                    raw_dict[config] = {}
                raw_dict[config][case_dict[Q]] = multipole['total dipole']
                print(filename, config, case_dict[Q], multipole['total dipole'])
        data_dict = {'config': [], 'dipole_l': [], 'dipole_m': [], 'dipole_h': []} 
        for config, value in raw_dict.items():
            data_dict['config'].append(config)
            data_dict['dipole_l'].append(value['dipole_l'])
            data_dict['dipole_m'].append(value['dipole_m'])
            data_dict['dipole_h'].append(value['dipole_h'])
            print(config)
        df4 = pd.DataFrame.from_dict(data_dict)
        return df4

        text += '      g09c=$(pgrep -c g09 2>/dev/null)\n'

        text += 'done' + '\n'
        text += 'wait' + '\n'

    def _closest_by_mass(self, mass: float, candidates: list[str], tol: float) -> str | None:
        best = None
        best_err = None
        for sym in candidates:
            err = abs(mass - self.MASS_REF[sym])
            if best_err is None or err < best_err:
                best, best_err = sym, err
        if best_err is not None and best_err <= tol:
            return best
        return None
        ################################################################################## 
    def gaussian_symbol_from_atomname(self, atomname: str, mass: float | None = None) -> str:
        name=atomname
        if not name:
            raise ValueError("Empty atomname cannot be resolved")
        up = name.upper()
        # 1) explicit dummy sites -> Gaussian Bq
        # eg MW, EP, VS, LP, DUM (with optional digits: MW1, EP2 etc)
        for pref in self.DUMMY_PREFIXES:
            if up.startswith(pref):
                return "Bq"
        # 2) handle the NA ambiguity using mass if present
        if up.startswith("NA") and mass is not None:
            pick = self._closest_by_mass(mass, ["N", "Na"], tol=1.5)
            if pick is None:
                raise ValueError(f"Ambiguous atomname '{atomname}' with mass {mass:.3f}")
            return pick
        # 3) try two-letter element from first two characters, case insensitive
        if len(name) >= 2 and name[0].isalpha() and name[1].isalpha():
            cand2 = name[0].upper() + name[1].lower()  # CL -> Cl
            if cand2 in self.SUPPORTED_2:
                return cand2
        # 4) try one-letter element from first character
        cand1 = name[0].upper()
        if cand1 in self.SUPPORTED_1:
            return cand1
        # 5) mass fallback across supported elements, if available
        if mass is not None:
            all_supported = list(self.SUPPORTED_1 | self.SUPPORTED_2)
            pick = self._closest_by_mass(mass, all_supported, tol=1.0)
            if pick is not None:
                return pick
        raise ValueError(f"Could not resolve element from atomname '{atomname}'")
        #################################################################################
    def Atom_Types(self,Gros,Masses):
        Gaus_List=[]
        for i,m in zip(Gros,Masses): # If the atomic number is present we could just use atom_dict...
            Gaus = self.gaussian_symbol_from_atomname(i, m)
            Gaus_List.append(Gaus)
        Gro_List=[]
        for n, i in enumerate(Gaus_List, start=1):
            Gro = f"{i}{n}"
            Gro_List.append(Gro) #This may need to work a little differently for QM and MM so we are assigning different values of the MM and QM parts of a system and will need a suggestion for this plus when like i=Ca or n>10
        Total_Atoms=0
        Dummy_List=[]
        for i in Gaus_List:
            if i =='H':
                Dummy_List.append(0)
            elif i=='Bq':
                Dummy_List.append(1)
            else:
                Dummy_List.append(0)
            Total_Atoms+=1
        return  Gro_List, Gaus_List, Dummy_List, Total_Atoms
