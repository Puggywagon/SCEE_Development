This script snippet starts with the continuation of the Pre_Eq_Simulation.py where we generate the box of filed with the number of molecules based on the experimental density. We start by inserting the solvent molecule into the box and appending the number of molecules to the .top file. I have kept the append to the top as a separate function as whenever you run into an issue with either the next steps its best not to repeat this step, and comment it out. The script creates the simulations folder where the production runs are stored, then loops through the number of replicas, temperatures and pressures set by the user. We then work through SCEE.py where we obtain the self-consistent dipole moment which is then used along with the values we obtain from [[2. Using the Vacuum Phase]] to calculate the induced dipole and dipole moment of the liquid based on the experimental gas phase dipole moment. ### How the Relevant Functions Work

The script presented here starts as a continuation from the pre-production run simulations we perform. We start with inserting the solvent molecules into the box of the nvt_vaccum2.gro, we append this number to the topology file. With these steps completed we are able to perform some basic minimisation steps. We start with energy minimisation, then perform 1ns NVT and then 1ns NpT. A quick note is that we merged the NPT with the production run NPT for phenol as something wasn't working and at this point I still don't know what went wrong with this.

We then calculate the dipole moment  and epsilon of the model from the production run simulations which are important for calculating the scaled dipole moments and dielectric constants corrections.

### How the Relevant Functions Work

In this version of the script we had an if else script that handled the different combinations of the topology file, based on a user input. 

`Calc_Qmax`
This step quickly reads the topology file. It counts the number of atoms within the molecule and the value with the highest charge.

`QM_Inputs`
This script starts by reading the topology and creating a dataframe from [ atoms ] and then reads the correct form for the [ atomtypes ]. In some scripts this is predetermined for the oplsff.itp file rather than the atomtypes in the topology which is a mistake in my code and needed fixing.

Then we loop through the atoms and match the atom typing in [ atoms ] to those in [ atomtypes ] and extracting information from this matching. The first match is for extracting the index of the atom of highest charge, we handle the special case of the water. This is due to the oniom is structured with the first line of this block identifying the total number of atoms in this group and which atom the dipole is localised.

We then perform this loop again but extract the sigma and epsilon values for the given atom types, with the exception of specific atom types which are predefined as they have a value of 0.0 in the main force fields. This may be related to what is causing the deviations but it is unlikely.

We then apply our charge scaling inputs to the charges of the molecule to allow for the three dipole moments to be calculated. This is how Miguel explained how to do this approach and accounts for water being the way it is.

The if the atom is a dummy it is denoted as a 'D' in the [ atomtypes ] structure but needs to be assigned a value of 1, while atoms are denoted as 'A' and are saved as 0, but sometimes this column isn't present or is missing a value and so is defaulted to a value of 0. 

Lastly we write the lines for those atoms according to the very specific structure given for each potential case. This is specific because any deviation would not be accepted by the fortran and we really need to convert that to python or something similar at some point.

`MM_Inputs`
The steps in this part of the script is very similar to those in the QM steps. The main differences are more on the structural output files. The biggest difference is the MM doesn't have the column for if it is the dummy bead or not at this level of theory. There is some special scripting for water  and probably can be expanded to similar systems, where the charge in the MM level is localised on the dummy bead where as in the QM it is localised on the element represented by the dummy.

`get_atomtypes`
This is reading in the [ atomtypes ] part of the file that is structured based on the columns provided in the opls or topology file. This is stored and saved as a dataframe.

`get_atoms`
This reads the [ atoms ] found in the topology or itp file. The structure of this should maintain some consistency across the different topology files.

`get_included_files`
This step identify the files that are # included in the .top file such as .itps which is how our input files are structure

`gro_to_gaus`
This is a list of gromacs atom types that I have considered the most commonly used for our files as stored in the atomtypes list. I use this to convert those atom types into ones that can be used for the elements list in gaussiann.

`Counting_Molecules`
The last line in the oniom file is the number of solvent molecules in the system so we have this as a last step in generating the input file.

`Gen_File`
This is a structural starting point from the oniom input file, including the name of the system, the number of configurations that have been extracted and are involved in the calculation and the cut off radius of the cluster.

### How the Relevant Functions Work

This scripts starts by processing the configurations using the oniom script  to take them from a format extracted from the md trajectories to a format accepted by Gaussian. We then use those configurations in the geometry optimisation (v0) and then dipole moment calculations (v1). I will note the 50Mw is the step that sets a limit of the memory used (might not be the right term) to 50Mw as some of the aromatic calculations were crashing because this was missing.

We then calculate the dipole moments and perform our processing. This part is written in this way as I was finding that some of the configurations were crashing but not all of them. This came about because of the memory issue in the aromatics. When we introduced the value it was originally set to 32 Mw, I upped it to 50 as the majority said these values were not high enough. I had a single calculation out of the 600 crash because this value wasn't high enough. I added a means to handle the crashes without crashing the entire script. Now we have situations where crashed calculations are accounted for. This does mean that some of the calculations have less than 200 configurations.

    x = np.asarray(x, dtype=float)

    hi = q3 + k * iqr
    out = (x < lo) | (x > hi)
    keep = ~out

    def _closest_by_mass(self, mass: float, candidates: list[str], tol: float) -> str | None:

        if best_err is not None and best_err <= tol:

    def gaussian_symbol_from_atomname(self, atomname: str, mass: float | None = None) -> str:
        name=atomname
        if not name:
            raise ValueError("Empty atomname cannot be resolved")
        up = name.upper()
        # 1) explicit dummy sites -> Gaussian Bq
        # eg MW, EP, VS, LP, DUM (with optional digits: MW1, EP2 etc)
        for pref in self.DUMMY_PREFIXES:
            if up.startswith(pref):
                return "Bq"
        # 2) handle the NA ambiguity using mass if present
        if up.startswith("NA") and mass is not None:
            pick = self._closest_by_mass(mass, ["N", "Na"], tol=1.5)
            if pick is None:
                raise ValueError(f"Ambiguous atomname '{atomname}' with mass {mass:.3f}")
            return pick
        # 3) try two-letter element from first two characters, case insensitive
        if len(name) >= 2 and name[0].isalpha() and name[1].isalpha():
            cand2 = name[0].upper() + name[1].lower()  # CL -> Cl
            if cand2 in self.SUPPORTED_2:
                return cand2
        # 4) try one-letter element from first character
        cand1 = name[0].upper()
        if cand1 in self.SUPPORTED_1:
            return cand1 
        # 5) mass fallback across supported elements, if available
        if mass is not None:
            all_supported = list(self.SUPPORTED_1 | self.SUPPORTED_2)
            pick = self._closest_by_mass(mass, all_supported, tol=1.0)
            if pick is not None:
                return pick
        raise ValueError(f"Could not resolve element from atomname '{atomname}'")

    def _iqr_masks(self,x, k):
        x = np.asarray(x, dtype=float)
        q1, q3 = np.percentile(x, [25, 75])

        lo = q1 - k * iqr
        hi = q3 + k * iqr
        out = (x < lo) | (x > hi)
        keep = ~out

    def plot_dipoledist_filtered(self,Molecule, k, bin_width=0.25, x_ceil=10.0):
        parser = argparse.ArgumentParser()
        parser.add_argument('--show', type=str, default='True', help='plot figures')
        args = parser.parse_args()
    
        df_unfiltered = self.read_data()
        x_all = df_unfiltered['mu_liquid'].astype(float).to_numpy()
        x_all = x_all[np.isfinite(x_all)]
        if x_all.size < 5:
            raise ValueError("Not enough dipole samples to form a distribution.")

        keep, out, (q1, q3, iqr, lo, hi) = self._iqr_masks(x_all, k=k)
        x_keep = x_all[keep]
        x_out  = x_all[out]
    
        mu    = x_keep.mean()
        sigma = x_keep.std(ddof=0)
        if sigma == 0.0:
            raise ValueError("Sigma is zero. Check your data.")

        # Gaussian threshold for axis limits
        gauss_threshold = 0.001
        x_test = np.linspace(0.0, x_ceil * 2, 10000)
        gauss_test = self._normal_pdf(x_test, mu, sigma)
        gauss_peak = gauss_test.max()
        above_thresh = x_test[gauss_test >= gauss_threshold * gauss_peak]
        xmin_gauss = max(0.0, np.floor(above_thresh.min() / bin_width) * bin_width)
        xmax_gauss = min(x_ceil, np.ceil(above_thresh.max() / bin_width) * bin_width)

        # Gap detection to avoid long empty tails
        counts, edges = np.histogram(x_all[x_all <= x_ceil],
                                     bins=np.arange(0, x_ceil + bin_width, bin_width))
        nonzero_bins = np.where(counts > 0)[0]
        last_populated = edges[nonzero_bins[-1] + 1]
        gap_cut = None
        for i in range(len(nonzero_bins) - 1):
            gap = nonzero_bins[i+1] - nonzero_bins[i]
            if gap > 3:
                gap_cut = edges[nonzero_bins[i] + 1]
                break
        if gap_cut is not None:
            xmax_data = np.ceil((gap_cut + 0.5) / bin_width) * bin_width
        else:
            xmax_data = np.ceil((last_populated + 0.5) / bin_width) * bin_width

        xmax = min(x_ceil, max(xmax_gauss, xmax_data))
    
        # Extend to show mild outliers within 2 sigma
        mild_out = x_out[np.abs(x_out - mu) <= 2 * sigma]
        if mild_out.size:
            xmin_mild = np.floor(mild_out.min() / bin_width) * bin_width
            xmax_mild = np.ceil(mild_out.max() / bin_width) * bin_width
            xmin = max(0.0, min(xmin_gauss, xmin_mild))
            xmax = min(x_ceil, max(xmax, xmax_mild))
        else:
            xmin = xmin_gauss
    
        bin_edges = np.arange(xmin, xmax + bin_width, bin_width)
        bw = bin_edges[1] - bin_edges[0]

        fig, ax = plt.subplots(figsize=(8, 6))
        ax.hist(x_keep, bins=bin_edges, alpha=0.9,color='purple', label="Data (outliers removed)")
        if x_out.size:
            x_out_visible = x_out[(x_out >= xmin) & (x_out <= xmax)]
            if x_out_visible.size:
                ax.hist(x_out_visible, bins=bin_edges, alpha=0.9,color='orange', label="Outliers (IQR rule)")

        x_line = np.linspace(xmin - bin_width, xmax + bin_width, 400)
        y_line = self._normal_pdf(x_line, mu, sigma) * x_keep.size * bw
        ax.plot(x_line, y_line, color='#008080', linewidth=2, label="Gaussian fit")

        ax.set_xlim(xmin, xmax)

        tick_spacing = round(raw_spacing * 2) / 2
        tick_spacing = max(tick_spacing, 0.5)
        ax.set_xticks(np.arange(xmin, xmax + tick_spacing, tick_spacing))
        ax.set_xlabel(r'$\mu_{liquid}$ / D', fontsize=16)
        ax.set_ylabel('Frequency', fontsize=16)
        ax.legend(frameon=False, fontsize=12)
        ax.tick_params(axis='both', which='major', labelsize=12)
        plt.tight_layout()

        plt.savefig(f'../figures/dipole_distribution_{Molecule}_filtered.pdf', bbox_inches="tight", dpi=300)
        plt.close(fig)

        stats = {
            'Molecule':   [Molecule],
            'N_total':    [x_all.size],
            'N_kept':     [x_keep.size],
            'N_outliers': [x_out.size],
            'mean_D':     [round(mu, 4)],
            'std_D':      [round(sigma, 4)],
            'median_D':   [round(np.median(x_keep), 4)],
            'IQR_lo':     [round(lo, 4)],
            'IQR_hi':     [round(hi, 4)],
            'q1':         [round(q1, 4)],
            'q3':         [round(q3, 4)],
        }
        stats_df = pd.DataFrame(stats)
        stats_df.to_csv(f'../figures/vectors/dipole_stats_{Molecule}_filtered.csv', index=False)
        print(stats_df.to_string(index=False))
